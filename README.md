# Enterprise Employee Data Entry Portal

A responsive, lightweight web application built with **Flask (Python)** and **SQLite** for managing employee records with real-time validation and database insertion.

---

## Features

* **Responsive UI:** Fully optimized for desktop web browsers and mobile devices.
* **Smart Input Validation:** Checks for valid email address formats before submission.
* **Duplicate Prevention:** Prevents duplicate email entries with instant user feedback.
* **Dynamic Record Display:** Views current database entries sorted in ascending order by ID.
* **Mobile-Optimized Experience:** Touch-friendly select menus and horizontally scrollable data tables.

---

## Tech Stack

* **Backend:** Python 3, Flask
* **Database:** SQLite
* **Frontend:** HTML5, CSS3, JavaScript (Jinja Templating)
